# RoboRumble Archipelago

Groundwork for [Archipelago](https://archipelago.gg) support in RoboRumble (1998, Metropolis / TopWare).
So far this repo contains a game patch that makes the game run well on modern Windows and the
tooling used to reverse engineer it; the apworld comes next.

## The patch

A proxy `winmm.dll` that goes next to the game exe in `DATA\` (the GOG release already ships an
ogg-winmm there, which it replaces). It forwards everything to the real winmm and adds:

| Feature | How |
| --- | --- |
| CD music from `DATA\MUSIC\Track02-09.ogg` | MCI `cdaudio` emulated; music volume via the mixer's CD line; skips the noise burst at the start of GOG's Track02 rip |
| Windowed mode, no display mode changes | software renderer: fake DirectDraw drawn with GDI; Glide on nGlide: nGlide kept windowed inside the patch's window; Glide/D3D on dgVoodoo2: dgVoodoo windowed |
| Mouse in a window | cursor/click coordinates mapped to 640x480, cursor confined while the game is in front |
| Mouse wheel zoom | wheel = Insert / Page Up, posted to the game's message loop |
| RTS-style mission controls | right click moves/attacks, left click on the ground deselects, right drag pans the camera, WASD scrolls; the game's click code is patched at a few points |
| Keeps running in the background | the game no longer pauses or minimizes itself when it loses focus |
| Better zoom (from the "Better Zoom and Bug Fixes" mod) | `[adjust]` values merged into `adjust.ini` at startup |
| Fixed sound effects | clipped recordings rebuilt (declip), hard edges faded, door scrape muted |
| Fast textures on nGlide | the game's YIQ (NCC) textures are decoded once by the patch; nGlide re-decoded them on every texture switch (zoomed out: 15-25 fps, now 60) |
| Glide at the game's own pace (~45 fps) | the game asks Glide for every second refresh (30 fps), which slows it down |
| Developer window | win/lose missions, unlocks, money, console commands, live `adjust.ini` values |
| File overrides | `DATA\override\<path>` replaces the same file inside the `.pak` archives |

Everything is configured in `DATA\rrpatch.ini` (see `patch/rrpatch.ini` for the commented
defaults) and logged to `DATA\rrpatch.log`.

### Build and install

```
sh patch/build.sh                                        # needs llvm-mingw (i686)
python tools/install_patch.py "D:\Games\...\RoBoRumble"  # copies winmm.dll + rrpatch.ini
python tools/install_patch.py "D:\Games\...\RoBoRumble" --remove
```

Optional: `--dgvoodoo <unpacked dgVoodoo2>` installs dgVoodoo's Glide/DirectDraw dlls with a
windowed `dgVoodoo.conf`; `--glide nglide|dgvoodoo` switches the Glide wrapper. nGlide is the
recommended Glide wrapper (dgVoodoo leaves trails in the robot builder's 3D preview).

The GOG `rr_glide.exe` is marked "run as administrator" by GOG's compatibility shim; it runs
fine without, e.g. with the environment variable `__COMPAT_LAYER=RunAsInvoker`.

## Layout

| Path | What |
| --- | --- |
| `patch/src/proxy.c` | DLL entry, config, winmm forwarding table |
| `patch/src/cdaudio.c` | CD audio emulation (stb_vorbis) |
| `patch/src/ddwin.c` | fake DirectDraw, window and mouse handling, wheel zoom |
| `patch/src/glidewin.c` | Glide: nGlide windowing, swap interval, fps log |
| `patch/src/vfs.c` | `.pak` override hook, `adjust.ini` merge, sound effect fixes |
| `patch/src/input.c` | game mode tracking, mouse button swap |
| `patch/src/devui.c` | developer window |
| `patch/src/texcache.c` | YIQ texture decode cache for nGlide |
| `patch/src/soundlog.c`, `glidetrace.c`, `prof.c` | diagnostics (`log_sound`, `trace_glide`, `profile`) |
| `patch/src/gen/` | export stubs generated by `tools/gen_winmm_proxy.py` |
| `tools/install_patch.py` | install / remove / switch Glide wrapper |

The exes are not modified on disk. Code hooks are found by byte patterns at runtime, so the
same dll works for `rr_soft.exe`, `rr_dx5.exe` and `rr_glide.exe` of both the Steam and the GOG
release (soft/dx5 are identical between them).
